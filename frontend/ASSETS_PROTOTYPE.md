# Ассеты нового прототипа

Изображения и иконки из Figma не удалось выгрузить автоматически: файл
отдаёт их по ссылкам на `www.figma.com`, а исходящие запросы к этому домену
режет политика окружения, в котором собиралась ветка. Поэтому картинки
нужно выгрузить руками — один раз.

**Сейчас все слоты заполнены сгенерированными заглушками** — абстрактными
подложками в палитре макета (`scripts/generate-placeholders.py`). Это не
фотографии: скачать что-либо из интернета из окружения сборки тоже нельзя,
все хосты с изображениями режет та же политика. Заглушки нарисованы с нуля,
поэтому вопросов с лицензиями нет.

Чтобы поставить настоящие снимки, просто положите файлы поверх — пути в коде
и в базе уже совпадают, менять ничего не нужно. После добавления файлов
нужна пересборка фронтенда: Next снимает список `public/` на этапе сборки,
и новые файлы иначе отдаются как 404.

**Файл макета:** [Облачный коворкинг](https://www.figma.com/design/WVj3q2gsEAK6X38UIfBvGY),
секция **New**. Экспорт: выделить слой → правая панель → Export → PNG (2x).

## Заглушки

`scripts/generate-placeholders.py` перерисовывает все подложки одной командой:

```bash
cd frontend && python3 scripts/generate-placeholders.py
```

Скрипт зависит только от Pillow и берёт цвета из палитры макета. Удалять его
после замены картинок не обязательно — он не участвует в сборке.

## Иконки

Иконки в интерфейсе нарисованы инлайновыми SVG прямо в компонентах, а не
подтягиваются из макета: так они наследуют `currentColor` и не тянут
дополнительных запросов. Если нужна пиксельная точность с макетом —
выгрузите SVG из Figma и замените разметку в соответствующем компоненте.
