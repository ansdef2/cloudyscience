# 3D-модели оборудования

Каждая модель — в своей папке. Поддерживаются `.glb`, `.gltf` и `.obj`.

```
models/
  frezer/
    model.obj
    model.mtl      ← материалы, если есть
    texture.jpg    ← текстуры, если есть
  printer/
    scene.glb
```

Для OBJ просмотрщик ищет рядом одноимённый `.mtl`. Если его нет,
модель показывается с нейтральным серым материалом — геометрия
видна, цвета нет.

Привязка моделей к позициям оборудования — `deploy/link-3d-models.py`.

Файлы попадают в образ на этапе сборки, поэтому после добавления
новых моделей нужна пересборка: `dc up -d --build`.
