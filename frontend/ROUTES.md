# Маршруты приложения

Next.js App Router, все страницы лежат в `src/app`, вёрстка — в `src/screens`.

| Маршрут | Экран | Что показывает |
|---|---|---|
| `/` | `Landing` | Лендинг: что такое «Облако науки», живые цифры, кнопка входа |
| `/home` | `HomePage` | Карта с кластерами (сворачивается в карточку и разворачивается на весь экран), поиск, карточки аренды, свободные места на курсы, «Актуальное» и лента постов |
| `/search` | `SearchPage` | Поиск с общей выдачей и фильтром: учреждения, оборудование, курсы, эксперты (`?q=&type=`) |
| `/equipment` | `EquipmentCatalog` | Каталог оборудования с поиском и фильтром по типу (`?type=`) |
| `/equipment/[id]` | `EquipmentDetail` | Карточка оборудования: переключатель 3D/JPG и таблица характеристик по разделам |
| `/booking/[equipmentId]` | `BookingPage` | Бронирование в три шага: загрузка файлов и тип аренды; календарь на 90 дней и свободные слоты по часам работы; подтверждение с комментарием |
| `/institution/[id]` | `InstitutionDetail` | Карточка учреждения с контактами и направлениями; меню «…»: поделиться, Яндекс Карты, маршрут, адрес |
| `/course/[id]` | `CourseDetail` | Карточка курса, запись (30 мест, одна на человека), прогресс по этапам — только записанным |
| `/courses` | `CoursesPage` | Все курсы |
| `/post/[id]` | `PostDetail` | Публикация целиком; сюда ведёт «Поделиться», превью для мессенджеров |
| `/people` | `PeoplePage` | Эксперты (консультации) и обучающиеся (написать, позвать в команду), `?tab=learners` |
| `/chats`, `/chats/user/[id]`, `/chats/team/[id]` | `ChatsPage`, `ChatRoom` | Список чатов и переписка — личная или командная |
| `/teams`, `/teams/[id]` | `TeamsPage`, `TeamDetail` | Исследовательские команды: тема, участники, чат, брони |
| `/profile` | `ProfilePage` | Мои брони (файлы, данные для подключения), консультации, ссылки на уведомления, чаты, команды, настройки и админку |
| `/settings` | `SettingsPage` | Фото, имя, пароль, выход на других устройствах, документы, удаление аккаунта |
| `/notifications` | `NotificationsPage` | Все уведомления (на десктопе — ещё и колокольчик в шапке) |
| `/admin` | `AdminPage` | Записи на курс, брони, консультации, пользователи, жалобы, каталог (`?tab=`) |
| `/login` | `Login` | Вход, «Запомнить меня», сохранение пароля в браузере, «Забыли пароль?»; `?next=` — куда вернуть после входа |
| `/register` | `Register` | Регистрация: дата рождения, согласие с документами; до 14 лет — почта родителя |
| `/forgot`, `/reset?token=` | `ForgotPassword`, `ResetPassword` | Ссылка для сброса пароля на почту и новый пароль по ней |
| `/consent?token=` | `ParentConsent` | Согласие родителя на обработку данных ребёнка до 14 лет |
| `/privacy`, `/terms` | — | Политика конфиденциальности и пользовательское соглашение |
| `/robots.txt`, `/sitemap.xml` | — | Для поисковиков: личные разделы закрыты, карта сайта пересобирается раз в час |

## Переходы

- `/` → `/login`, `/register`, `/home` («Открыть карту»), `/course/[id]`
- `/home` → `/search` (поле поиска), `/equipment` (карточки аренды), `/course/[id]` (карусель курсов),
  `/institution/[id]`, `/equipment/[id]`, `/course/[id]` (список объектов кластера на карте)
- `/course/[id]` → `/login?next=/course/[id]` (запись без входа)
- `/search` → `/institution/[id]`, `/course/[id]`, `/equipment/[id]`, `/booking/[id]`
- `/equipment` → `/equipment/[id]`, `/booking/[id]`
- `/equipment/[id]` → `/booking/[equipmentId]`
- `/institution/[id]` → `/course/[id]`
- `/login` ↔ `/register` (с сохранением `?next=`), после входа → `next` или `/home`
- значок облака в шапке внутренних экранов → `/home`; «Выйти» в меню профиля → `/`

## Дизайн

Все экраны используют дизайн-систему прототипа: токены из `src/styles/prototype.css`,
общие `ProtoTopBar`, `ProtoSearchField`, `ProtoCalendar`. Экранов на старом дизайне
не осталось.

На телефоне каждый экран — колонка шириной макета (360 px). С 960 px включается
десктоп: общая шапка `SiteHeader` с разделами и профилем, содержимое в сетке до
1200 px (класс `protoPage`), двухколоночные раскладки у главной, оборудования,
курса и учреждения, сетки карточек в каталоге и поиске. Мобильная панель
скрывается классом `protoMobileOnly`, десктопные элементы — `protoDesktopOnly`.

На телефоне внизу закреплена панель `BottomNav` из макета — «Главная», «Люди»,
«Курсы», «Профиль»; на десктопе те же разделы в шапке, плюс значок чатов с
числом непрочитанных. Общие элементы новых экранов — `src/styles/ui.module.css`.
