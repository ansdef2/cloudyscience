# Журнал изменений

Номер версии — в `server/package.json` и `frontend/package.json`. Сайт
показывает его в подвале лендинга, API — в `GET /api/health`.

## 1.2.1 — 13 октября 2026

### Бронирование
- Проверка пересечений на сервере: две брони одного времени не проходят,
  даже если отправлены одновременно
- Свободное время по часам работы оборудования, календарь на 90 дней вперёд
- Загрузка файлов к брони; их видят только автор, команда и администратор
- Администратор пишет в бронь, как подключиться при дистанционной аренде;
  закрытое оборудование не бронируется

### Аккаунты и документы
- Сброс пароля по ссылке из письма; смена пароля завершает прежние входы
- Настройки: фото, имя, пароль, выход на других устройствах, удаление аккаунта
- Политика конфиденциальности и пользовательское соглашение, согласие при
  регистрации; для детей до 14 лет — согласие родителя
- Ограничение частоты запросов, заголовки безопасности, посты — только от
  администратора

### Общение
- Уведомления: колокольчик и страница `/notifications`, письма о важном
- Сообщения в чатах приходят сразу (WebSocket)
- Приглашения в команду вместо добавления без спроса
- Жалобы и блокировка собеседника

### Админка
- Пользователи: блокировка, роли, ссылки сброса пароля и согласия родителя
- Жалобы с текстом сообщения и решениями
- Каталог: учреждения, оборудование, курсы с модулями и этапами, эксперты,
  посты; уборка демо-данных

### Эксплуатация
- Автотесты бэкенда и проверки в GitHub Actions
- Ночной бэкап базы и загруженных файлов, ротация логов, письма об ошибках
- Фильтр по типу в поиске, меню «…» учреждения, `robots.txt` и `sitemap.xml`
